# SmartNote CLI

> 터미널에서 빠르게 메모를 작성하고 카테고리별로 관리할 수 있는 가벼운 텍스트 기반 메모 도구입니다.

## 소개
**SmartNote CLI**는 개발자 및 터미널 사용자가 복잡한 GUI 프로그램 없이 빠르게 아이디어나 할 일을 기록할 수 있도록 제작된 Command Line Interface 도구입니다. 텍스트 파일(Markdown) 기반으로 작동하며 local 데이터로 안전하게 보관됩니다.

## 주요 기능
- **빠른 메모 작성**: 터미널 명령어 한 줄로 즉시 메모를 작성하고 저장합니다.
- **카테고리 및 태그 관리**: `#개발`, `#아이디어` 등 태그를 지정해 손쉽게 메모를 검색 및 분류할 수 있습니다.
- **Markdown 자동 변환**: 저장된 메모를 일관된 Markdown 형식으로 깔끔하게 포맷팅해 줍니다.
